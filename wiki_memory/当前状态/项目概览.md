# 项目概览

## 项目目标与阶段

FluxDL为Windows-first、本地优先yt-dlp桌面客户端，React/TypeScript/Vite + Tauri2/Rust、Midnight Glass。已有真实双窗口、单媒体视频/MP3、串行队列、取消/重试、历史、设置、托盘和安全退出；外部引擎由用户配置，不内置下载。版本0.2.0，原主线已有增量SQLite、版本IPC、完整本地诊断/Trace/报告与受控发布流程。

当前专项分支增加真实低频吞吐、5s/10s窗口、停滞观测、协议枚举与阶段查询合并；自动有界Manager/独立CLI/显式本地代理对照已完成。没有产品代理设置/默认并发/chunk/缓存改造：当前数据不足以证明稳定速度收益。仅专项分支交付，不合并main或更新旧正式包。
