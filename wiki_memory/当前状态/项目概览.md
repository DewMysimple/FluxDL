# 项目概览

## 项目目标与阶段

FluxDL是Windows-first、本地优先的yt-dlp桌面客户端，React/TypeScript/Vite + Tauri2/Rust，Midnight Glass。真实双窗口、单媒体视频/MP3、串行队列、取消/重试、历史、设置、托盘与安全退出均已交付；外部引擎由用户配置，不内置下载。

当前版本0.2.1：保留本地白名单诊断，增加首输出/before_dl/进度等待、Rust短期有界可信预览、真实准备计时/任务摘要、编译revision及会话环境分组。命中仍做后端安全复核；失效完整重提取。原创HTTP同程序A/B各20次，入队响应p50 1235.3→6.2ms，入队到首进度2104.084→862.026ms；spawn→首进度基本未变，不外推互联网。
