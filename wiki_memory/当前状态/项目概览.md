# 项目概览

## 项目目标与阶段

FluxDL 是 Windows-first、本地优先的 yt-dlp 桌面客户端，技术栈 React / TypeScript / Vite + Tauri 2 / Rust，界面为 Midnight Glass。用户原始目标是可解析、可下载、可管理任务且能生成 Windows 安装包的 MVP，正式需求见 `prompt/FluxDL_Codex_MVP_Prompt.md`。

当前实现版本 0.1.0：真实双窗口、外部引擎检测、单媒体视频/音频下载、串行队列、取消/重试、SQLite 设置和历史、主题/密度、托盘与安全退出已实现。Windows NSIS 和独立程序已在本机构建。当前为 MVP 已交付并接入 standard 工程记忆及 Git 版本控制的维护阶段；验证覆盖及未验收项目见 `docs/validation.md`，不能将本机结果泛化为所有站点和平台可用。

## 核心入口

| 范围 | 入口 |
| --- | --- |
| 项目使用与构建 | `README.md`、`package.json`、两份 lockfile |
| 前端与展示状态 | `src/main.tsx`、`src/App.tsx`、`src/lib/api.ts`、`src/stores/app.ts` |
| 后端命令与模型 | `src-tauri/src/lib.rs`、`models.rs` |

开发入口为 `npm ci` 后 `npm run desktop:dev`。`npm run dev` 仅浏览器预览，真实下载需要桌面运行。完整模块关系见 [系统架构](系统架构.md)。

首批工程提交 `2974868e3cb486f304995f0ab083f9b04c78987f` 覆盖现有 MVP、工程记忆和必要文档维护，已成功 `git push -u origin main`，随后实际核对远程 `refs/heads/main` 与本地 HEAD 一致；`main` 已跟踪 `origin/main`。这记录的是本页收尾更新前的交付基线，后续提交以 Git 历史和实际远程为准。

后续接续执行 `git status --short --branch`、`git log -1 --oneline`、`git remote -v` 并获取实际远程状态，不能沿用此处的初始空仓库或首批 SHA。
