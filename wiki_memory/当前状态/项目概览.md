# 项目概览

## 项目目标与阶段

FluxDL是Windows-first、本地优先的yt-dlp桌面客户端，React/TypeScript/Vite + Tauri2/Rust，Midnight Glass。MVP能力已交付：真实双窗口、单媒体视频/MP3、串行队列、取消/重试、历史、设置、托盘与安全退出。媒体引擎由用户配置，不内置下载。

当前源码/元数据0.2.0工程优化已完成：前端模块化、增量SQLite、版本增量IPC、Engine/Process/Commands/集中转换/错误脱敏。前端90项、Rust80项及独立fixture通过，真实桌面15项、原生版本补测14通过/1未测；三档基准实测、最终NSIS和debug/release构建成功。产物SHA256和限制以工程验证报告为准。
