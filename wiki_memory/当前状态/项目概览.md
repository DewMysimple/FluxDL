# 项目概览

## 项目目标与阶段

FluxDL是Windows-first、本地优先的yt-dlp桌面客户端，React/TypeScript/Vite + Tauri2/Rust，Midnight Glass。真实双窗口、单媒体视频/MP3、串行队列、取消/重试、历史、设置、托盘与安全退出均已交付；外部引擎由用户配置，不内置下载。

当前版本0.2.0，可观测性迭代已实现：Rust结构化白名单JSONL/轮转/故障降级、真实Trace/阶段耗时、自动Codex报告、Workspace诊断中心四视图、手动安全ZIP/Explorer定位。保留二次安全复核、增量SQLite、版本IPC和attempt准入。测得重复日志查询瓶颈后增加有界查询缓存，没有强行缓存媒体或声称下载加速。
