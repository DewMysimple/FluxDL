1. 运行 `git status --short --branch`、`git log -1 --oneline`、`git remote -v`，确认 `origin` 为指定 GitHub 仓库；获取远程后核实实际 upstream，保留现有修改。

3. 对本任务归属的差异审查后提交，执行 `git push`（首次建立 upstream 使用 `git push -u origin main`）；以 `git rev-parse HEAD` 和 `git ls-remote origin refs/heads/main` 一致为交付判据。
4. CI 结果看仓库 Actions；本机旧测试和单纯推送成功都不证明远程构建通过。
