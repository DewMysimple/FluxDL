# 系统架构

## 模块职责与边界

React 入口 `src/main.tsx`；`App.tsx` 集中四个工作台页面、抽屉、设置与 Quick Capture，原生 CSS 在 `src/styles/app.css`。Zustand 仅保留后端快照和界面错误，不管理真实下载。前端 IPC 集中在 `src/lib/api.ts`，类型镜像在 `types.ts`，权威模型在 Rust `models.rs`。

`lib.rs` 注册命令并持有 `Arc<Manager>`；`manager.rs` 负责队列、状态机、设置、诊断和事件；`engine.rs` 负责可执行程序探测、媒体解析、参数、进度与错误诊断；`persistence.rs` 负责 SQLite；`process_job.rs` 负责 Windows Job；`windows.rs` 负责真实窗口、托盘相关系统操作和受控打开。`docs/IPC-contract.md` 汇总协议，变更时仍以命令注册和模型为准。

用户指定 Rust 本地后端与双窗口；Agent 在此范围内选择单一后端事实源、全量快照和串行 worker，已实现。好处是两个窗口和重启行为统一；代价是快照与数据库保存随历史量增长，相关取舍见 [持久化决策](../决策/ADR-001-后端事实源与持久化.md)。

## 数据流与依赖

用户粘贴 HTTP(S) URL → `probe_media` 调用 yt-dlp JSON 解析 → 展示真实格式 → `enqueue_download` 再次解析并校验 → Rust FIFO worker 执行参数数组命令 → JSON 标记解析真实下载/后处理进度 → 检查退出码及目录内最终媒体文件 → 保存状态并广播。重试复用既有媒体元数据、移到队尾，不再解析；需要刷新站点格式时应重新解析并新建任务。来源：`manager.rs`、`engine.rs`。

`app-state-updated` 发送完整快照，进度约 4Hz；初始和重新聚焦时前端主动读取，事件监听卸载清理。`workspace-close-requested` 控制活动任务关闭提示；`shutdown-failed` 恢复退出失败界面。设置草稿不会被仅有进度变化的快照覆盖。来源：`src/App.tsx`、`src/lib/api.ts`。

SQLite 位于系统 AppData 的 `io.fluxdl.desktop/fluxdl.sqlite3`；状态变化及时保存、进度约 2 秒一次，重启将所有残留活动任务（含 queued）标为 Interrupted，必须主动重试。损坏文件备份后重建。同步事务持有队列状态锁并重写任务集合，文件存在性查询则在锁外异步执行。来源：`persistence.rs`、`docs/persistence.md`。

外部引擎候选顺序为自定义 → 可选安装资源 → PATH；无效候选告警后继续回退。实际发布不捆绑 yt-dlp、FFmpeg、FFprobe 或 JS runtime。MP3/分离音视频合并需要 FFmpeg + FFprobe；Deno/Node 版本检测不能保证 EJS 完整。来源：`engine.rs`。

## 运行与部署

Tauri 创建两个真实单例 WebView：`workspace` 1120×740、最小 760×560；`quick` 632px 宽，通过 `?window=quick` 加载，逻辑高度 260–720 并受显示器边界约束。Quick 输入固定、仅结果滚动，隐藏不停止任务。主窗口关闭可后台继续；真正退出等待进程清理。来源：`tauri.conf.json`、`windows.rs`、`lib.rs`、`App.tsx`。

`npm run desktop:dev` 启动 Vite/Tauri；`npm run desktop:build` 生成 Windows x64 NSIS；`npm run release:stage` 整理 EXE、许可与 SHA256 到本机忽略目录 `release/`。WebView2 缺失时由安装器提供官方引导；媒体引擎由用户另配。`windows.yml` 对 push/PR/手动运行执行检查和打包。原 MVP 已完成本机构建，远程状态需另查 Actions。

## 证据与未核实项

2026-11-09 对当前未提交源码和配置作只读核实；本轮无业务代码变更、无新增业务测试结果。真实下载、串行、取消/重试及重启的历史证据见 `docs/validation.md` 和 `docs/validation/`。

Windows Job 在启动后加入，仍有极短创建/加入窗口；非 Windows 未保证完整后代进程清理。数据库未做大历史性能基准。系统 API、物理 DPI 和安装循环的未覆盖范围见 [已知问题](已知问题.md)。
