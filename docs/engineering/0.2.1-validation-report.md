## 原生边界与剩余风险

P0：当前已验证范围内未发现未解决P0。P1：额外功能复验曾一次引擎格式不可用，独立及最终复验未重现，不能声称排除偶发故障。缓存过期/站点格式改变仍需完整复核或用户重解析；文件指纹是配置/版本/文件元数据绑定，不声称防御有权替换引擎并伪造文件元数据的本机攻击者。20个经验样本不是总体SLA，外部引擎/网络内部仍有未知等待。历史分析有20,000事件与保留上限，磁盘永久失败/断电不保证零丢失。

P2：Win10、真实DPI/多屏、完整安装卸载、原始发行EXE直接运行、物理托盘图标点击及远程CI未新增验证。托盘最终使用已注册回调加所有权核验的原生菜单点击；设置入口UIA不可访问仍未测。安装器未签名，WebView2/外部引擎方案不变。

测试只管理自有debug进程、独立数据/profile/媒体。用户正式进程未由本轮工具停止；生产日志/SQLite只读核查，没有改路径/清历史。测试打开的Explorer保存启动前HWND，并在finally只关闭新开且属于自有诊断目录的窗口，实际验证关闭完成；保留原有窗口，不结束Explorer进程。
